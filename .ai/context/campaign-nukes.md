## Wiki Architecture

The wiki is implemented with these pieces:

- **Routing**: `src/routes/wiki/+page.{svelte,server.ts}` (index) + `src/routes/wiki/faq/[slug]/+page.{svelte,server.ts}` (detail). Layout is in `src/routes/wiki/+layout.{svelte,server.ts}`.
- **Theme**: `src/routes/wiki/+layout.svelte` runs `use:wikiScope` on `<svelte:body>` so the wiki's own CSS variables (paper-cream bg, blue accent, soft shadows in `src/app.css` under `body[data-scope="wiki"]`) take effect on wiki routes only.
- **Content**: `static/wiki/faq/<slug>.md` files with simple `key: value` frontmatter. Edited as plain files; no TS rebuild to publish a copy edit.
- **Index**: `src/lib/wiki/manifest.ts` reads `static/wiki/manifest.json` at request time. Manifest is regenerated by `pnpm manifest` (`scripts/generate-wiki-manifest.ts`).
- **Renderer**: `marked` configured to drop raw HTML tokens. Wrapper is `src/lib/utils/wiki-render.ts`. Tests in `tests/wiki-render.test.ts` and `tests/wiki-frontmatter.test.ts`.

**Status**: SSR today. Prerender is deferred — see `.ai/prompts/wiki.md` "Prerendering" section.
