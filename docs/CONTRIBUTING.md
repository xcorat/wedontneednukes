# [ESTABLISHED] Contributing to WeDoNotNeedNukes

WeDoNotNeedNukes is an open, community-driven project aiming to scale campaign pledges and actionable content.

## How to Get Involved

### Code Contributions
- AI-assisted development is highly encouraged. Please read our [Agent Guide](../.ai/AGENTS.md) before starting.
- Review our [Code Conventions](../.ai/context/conventions.md) to ensure your PRs align with Svelte 5 and CF Workers paradigms.
- **PR Process**: Fork the repo, create a branch, submit a PR with a clear description. (Process will mature as the project grows).
- Improving the UI and backend is one of our primary community contribution campaigns.

### Content Contributions
The community can submit memes, videos, and FAQ edits to enhance the campaign landing pages.
