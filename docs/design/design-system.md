# [DRAFT] Visual Design System

## The Aesthetic
The design language is **cartoonish, similar to Android 2D games**. It is bright, bold, friendly, and accessible, moving away from overly sterile or dark corporate designs.

## Design Tokens

| Token | Value | Usage |
|---|---|---|
| Primary | `#E53935` (bright red) | CTAs, headers, primary buttons |
| Secondary | `#FFD600` (vivid yellow) | Highlights, badges, accents |
| Background | `#FFFDE7` (warm cream) | Main page background |
| Surface | `#FFFFFF` (white) | Cards, modals, elevated surfaces |
| Text | `#212121` (near-black) | Body text, readable copy |
| Text Muted | `#757575` (gray) | Secondary text, less important info |
| Success | `#43A047` (green) | Confirmations, success states |
| Font Display | `Fredoka One` (or similar) | Headers — rounded, bold, cartoonish |
| Font Body | `Nunito` or `Inter` | Body — clean, highly readable |
| Border Radius | `1rem` (16px) | Large, friendly curves on elements |
| Shadows | Flat / slight drop | Emphasizes the 2D game feel |

## Component Style Notes

- **Choice Blocks**: Large, full-width cards with bold text and a slight, flat drop shadow. Designed to be highly clickable.
- **FAQ Links**: Small, unobtrusive info icon + text next to choices. Subtle but always visible.
- **Buttons**: Large, rounded, featuring a playful hover animation (e.g., slight scale up or color shift).
- **Progress Indicator**: A friendly visual bar or step counter for the multi-step pledge flow.
- **Illustrations**: Flat vector graphics with bold outlines and a limited color palette matching the design tokens.
